# hot-strip-rolling-process-eda
Exploratory data analysis of hot strip rolling process parameters using Pandas


# Hot Strip Rolling Process EDA

## About the Project

This is an exploratory data analysis project based on a hot strip
rolling process dataset.

I used Python to study different process parameters such as
temperature, rolling speed, reduction ratio, deformation resistance,
friction coefficient and bending force.

## What I did

- Loaded and inspected the dataset
- Checked missing values and duplicate records
- Performed basic statistical analysis
- Studied the distribution of process parameters
- Analyzed relationships between important process variables
- Performed correlation analysis
- Compared bending force across material grades and lubrication types
- Added some process and metallurgical interpretation based on the data

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The dataset contains 1000 hot strip rolling process records and
includes parameters related to temperature, rolling conditions,
material properties and bending force.

The dataset was obtained from Kaggle.

## Main Focus

The main focus of this project is to understand which process
parameters are more strongly associated with bending force and to
explore the relationships between different hot strip rolling
parameters.

## Note

The observations in this project are based on the available dataset.
Correlation is used to identify relationships between variables and
does not itself establish causation.
